개폐기류 납품시험검사 통합패키지

개폐기류 9개 품목의 납품시험검사 성적서 작성과 품질관리를 지원하는 웹 도구 모음입니다. 설치 없이 아래 항목을 클릭해 브라우저에서 바로 사용하실 수 있습니다.

메인 프로그램

성적서 작성 프로그램

품목·규격을 선택해 발취부터 시험결과 입력, 종합판정까지 단계별로 진행하고 완성된 성적서를 PDF·XLSX로 저장합니다. 작성 내용은 XML로 저장·불러오기가 가능합니다.

열기 분석

품질관리 대시보드

저장된 성적서(XML) 파일을 한꺼번에 불러와 업체별·규격별 합격률과 불합격 항목 추이를 집계하여 보여줍니다.

열기 자동 산출

발취점검 수량표 (단일규격)

규격 하나를 선택하고 로트수량·품질등급을 입력하면 항목별 발취수량을 자동으로 계산해 줍니다.

열기 인쇄용

발취점검 수량표 (출력용)

9개 규격 전체의 시험항목별 발취수량을 한 장에 정리한 대조표입니다. A3 가로 인쇄에 맞춰 구성되어 있습니다.

사용 안내 · 모든 도구는 브라우저 안에서만 동작하며 입력하신 시험 데이터는 서버로 전송되지 않습니다. 작성 중인 내용은 저장(XML) 기능으로 직접 보관해 주세요. 최신 Chrome 또는 Edge 브라우저 사용을 권장합니다.
