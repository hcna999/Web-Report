## 1. 프로젝트 개요

한국전력공사(KEPCO) 개폐기류 9개 품목에 대한 **납품시험검사 성적서 작성**과 **품질관리 대시보드**를 제공하는 단일 파일(Single-file) HTML 웹앱 모음입니다. 빌드 과정 없이 브라우저에서 바로 열어 쓰는 구조이며, 서버 없이 클라이언트 JS만으로 동작합니다.

가장 중요한 원칙: **구매규격(GS-/ES- 번호 규격서)이 최상위 기준이고, 시험검사 업무절차서는 그 하위 실무 지침**입니다. 규격과 절차서·기존 코드가 다르면 구매규격을 따릅니다. 구매규격 원문 PDF와 이를 정리한 JSON 발췌본이 `관련 규정 및 지침/`에 있습니다.

## 4. 메인 앱 (`개폐기류 성적서 작성프로그램.html`) 아키텍처

### 4.1 데이터 모델
- `SPECS` 배열: 9개 규격 × steps(그룹) × items(개별 시험항목). 각 item은 `key/name/ref(조항)/crit(판정기준)/sampFn(발취함수)` 기본에, 다음 플래그로 렌더링 종류가 결정됨:
  - `full:true` → 전량검사, 값 입력 없이 일괄 양호/불량
  - `cert:true` → 성적서 대체(별첨 파일 업로드), `cycle`로 발취주기 문구
  - `resistance:'overhead'|'underground'` → 상별/단자쌍별 저항값 실측 그리드
  - `thr:{v,dir}` 또는 `range` → 값 입력 + **자동** 판정(measureAuto)
  - `measureManual:true` → 값 입력 + **수동** 판정 선택(measureManual)
  - 위 아무것도 없으면 기본값 `jdg`: 양호/불량 드롭다운만, **값 입력 불가**
- `S.per(n)`, `S.note1_dry` 등 `S` 객체: 발취수량 계산 함수 모음.
- `STATE`/`CUR`: 현재 선택 규격, 품질등급, 시료별 입력값 런타임 상태.
- `buildQIR()` / `qirToXML()` / `xmlToQIR()`: `kepco-qir-switchgear.v0.2` XML 스키마로 직렬화·역직렬화.

### 4.2 출력 기능
- **PDF 저장** (`btnDownloadPDF` → `downloadPDF(q,'both')`): html2pdf.js(jsPDF) 사용. 저장 컨테이너에 `reportStyles('.print-shell-export')`로 스코프 CSS를 주입해서 라이브 앱 스타일(`.item{border-radius}` 등)이 섞여 표 셀이 깨지는 문제를 막음. 워터마크(한전 로고, opacity 0.25)는 CSS `position:fixed`가 캔버스 래스터라이즈에는 페이지마다 반복 적용되지 않으므로, `pdf.setPage(p)` + `pdf.addImage()`로 매 페이지 수동 스탬핑.
- **XLSX 저장** (`btnPrintLoadedDetail` → `exportToExcel(q)`): 시트 순서 = 갑지 → 을지 → [저항측정 항목별 시트] → [성적서대체 항목별 시트] → 사진대지 → 시료 리스트. `safeSheetName()`으로 31자 제한/중복 시트명 처리.
- 버튼 문구는 전부 "출력"이 아니라 "저장"으로 통일(인쇄 대화상자 대신 파일 다운로드).

### 4.3 개선의견 → 구글시트 연동 (2026-08-03 추가, ⚠️미완성)
- 상단바 **💬 개선의견** 버튼 → 모달(작성자명/의견) → `fetch(FEEDBACK_WEBAPP_URL, {mode:'no-cors', body: URLSearchParams})`로 Google Apps Script 웹앱에 POST.
- **`FEEDBACK_WEBAPP_URL` 상수가 아직 `'YOUR_APPS_SCRIPT_WEBAPP_URL_HERE'` 플레이스홀더 상태**입니다. 코드 위치: 메인 앱 `$('btnBack').onclick=...` 직후, `// ===== 개선의견 (Google Sheet 연동) =====` 주석 아래.
- 사용자가 구글시트 + Apps Script 웹앱을 만들고 배포 URL을 알려주면 이 상수만 교체하면 바로 동작. Apps Script `doPost` 예시 코드는 대화 이력 참고 (시트 헤더: 제출일시/작성자명/개선의견/출처).

## 5. 발취점검 수량표 2종

- **`(출력용)`**: 정적 HTML 표, A3 가로 인쇄 전용, 9규격×31행 매트릭스. JS 데이터 구조 없이 `<td>`에 값이 하드코딩되어 있어 규격 변경 시 수기로 셀을 찾아 고쳐야 함.
- **`(단일규격 자동산출용)`**: `FLAT_ITEMS`(37개 항목) + `SPEC_HEADERS` JS 객체 기반. 규격 1개를 선택하면 로트수량·품질등급 입력에 따라 `S_FNS`로 발취수량을 자동 계산. 항목 추가/이름 변경은 `FLAT_ITEMS` 배열과 상단 `TOOLTIP_DATA` 딕셔너리를 함께 수정해야 함(항목명 문자열이 두 곳에서 정확히 일치해야 툴팁이 매칭됨).

이번 세션에서 두 파일 모두 DRYAIR의 PT/O-링/부싱/고체절연물 4개 신규 성적서대체 항목과 GIB 헤더명("다회로차단기") 정정을 반영했습니다.

## 6. 이번 세션 주요 변경 이력 (2026-08-03)

1. **PDF 출력 버그 3종 수정**: `reportShell()`의 `${inner}` 누락으로 빈 페이지 나오던 문제, 로고 워터마크 base64가 잘려있던 문제, 표 셀이 알약 모양으로 깨지던 CSS 클래스 충돌 문제.
2. **PDF 저장물에 워터마크·페이지번호 스탬핑, 인쇄→저장 방식 전환**.
3. **구매규격 9종 전수 대조 감사**: `관련 규정 및 지침/구매규격 Json 파일/`의 요약본과 메인 앱 `SPECS` 배열을 1:1 대조.
   - **DRYAIR(GS-5925-0157)**: 성적서 별첨 4항목 누락 발견 → PT시험(7.2.20)/O-링 재질시험(7.2.19)/부싱시험(7.2.30)/고체절연물 물성시험(7.2.38) 추가.
   - **EFI(GS-5925-0135)**: 축전지 성능시험(batt)이 측정값형이 아니라 성적서 대체형(cert)이어야 함 → 수정.
   - **값 입력 누락 5개 유형 점검**: 최소동작/T-C특성, 펄스동작시험, 부분방전시험(PD)에서 `measureManual`/`thr`이 빠져 값을 못 넣던 항목 다수 발견·수정 (GIB의 cb_trip/cb_tc/cb_pd 포함, 발취수량도 규격 기준 매20대로 정정).
   - **GIB 품명 오류**: 발취점검 수량표 2종에서 "가스절연 부하개폐기"로 잘못 표기된 것을 "가스절연 다회로차단기"로 정정.
4. **`dataset_100_sets` 100세트 전체 재생성** (위 SPECS 변경사항 반영 + 기존에 100개 전부 빈 페이지였던 버그도 함께 해결됨).
5. **GitHub 연동**: `https://github.com/hcna999/Web-Report.git`(main)에 최초 커밋 푸시 완료. (단, 이 프로젝트 폴더 자체는 FUSE 마운트라 로컬 git 재사용 불가 — 위 2절 주의사항 참고)
